# Retail Sales Forecasting & Analytics System

## 📌 Project Overview

The **Retail Sales Forecasting & Analytics System** is an end-to-end data analytics project built using **Python, MySQL, Power BI, and Machine Learning**.
The project focuses on analyzing historical retail sales data, generating business insights, visualizing performance through dashboards, and predicting future sales trends using machine learning.

This project simulates a real-world business analytics workflow from raw data preprocessing to forecasting and dashboard reporting.

---

# 🚀 Features

* ✅ Data Cleaning & Preprocessing
* ✅ Exploratory Data Analysis (EDA)
* ✅ Sales Trend Analysis
* ✅ Region-wise & Category-wise Analysis
* ✅ Profit & Loss Analysis
* ✅ SQL Database Integration
* ✅ Interactive Power BI Dashboard
* ✅ Sales Forecasting using Machine Learning
* ✅ Business Insights Generation

# 📊 Project Workflow

## 1️⃣ Data Cleaning & Preprocessing

* Removed duplicate records
* Handled missing values
* Fixed encoding issues
* Converted date columns into datetime format
* Created additional features like:

  * Year
  * Month
  * Day

## 2️⃣ Data Analysis

Performed analysis to identify:

* Top-selling products
* Monthly sales trends
* Region-wise sales performance
* Category-wise profit
* Loss-making products

---

## 3️⃣ SQL Integration

* Imported cleaned data into MySQL
* Performed SQL queries using:

  * GROUP BY
  * SUM
  * ORDER BY
  * Aggregation functions

---

## 4️⃣ Power BI Dashboard

Created an interactive dashboard containing:

* KPI Cards
* Monthly Sales Trends
* Regional Sales Analysis
* Category-wise Profit Analysis
* Loss-making Sub-category Analysis
* Interactive Filters (Slicers)

---

## 5️⃣ Machine Learning Forecasting

Implemented a **Linear Regression model** to:

* Predict future sales
